# Results Files

The final course-level project results are stored in:

- `hyperparameter_results.csv` — final 6-epoch manual tuning comparison
- `model_comparison.csv` — final 3-layer Custom CNN vs frozen ResNet18
- `ablation_results.csv` — additional augmentation ablation study

The file `custom_cnn_classification_report.csv` is retained from the earlier 4-layer CNN experiment for historical reference. It is **not** the classification report for the final 3-layer model and should not be used as the final submitted metric table.

Final submitted Custom CNN metrics:

- Test accuracy: 92.07%
- Weighted precision: 92.37%
- Weighted recall: 92.07%
- Weighted F1-score: 92.09%
