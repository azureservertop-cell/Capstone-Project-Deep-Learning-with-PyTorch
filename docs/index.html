Final Augmentation Choice

The final model uses a restricted random crop scale=(0.8, 1.0) and RandomHorizontalFlip. VerticalFlip, Rotation, and ColorJitter were tested separately but none improved the baseline, so they were not retained.

Main Finding

The same course-level 3-layer CNN improved substantially after restricting the crop range and extending manual tuning from four to six epochs. The final result supports using the simpler augmentation pipeline rather than adding preprocessing that did not improve validation or test performance.
